# Brief: contractor and agency track records (shared)

Today is 2026-11-17. We run a public transparency dashboard of government projects in Mumbai. We are adding a "Contracts" tab: which companies win Mumbai government contracts, from which agencies, how those projects went, and any documented penalties, terminations, blacklisting, investigations or court cases.

THIS IS PUBLISHED ABOUT REAL COMPANIES AND PEOPLE. Accuracy rules (non-negotiable):
- Only include events you found in a source you actually opened: official orders, court judgments/orders, agency press releases, CAG reports, stock-exchange disclosures, or reputable news (Times of India, Hindustan Times, Indian Express, The Hindu, Mint, Economic Times, Business Standard, Free Press Journal, Mid-day, ThePrint, Scroll, Reuters, PTI). No blogs, no social media, no unsourced claims.
- Classify every event with exactly one `kind`:
  "Penalty" (fine/liquidated damages imposed by the awarding body), "Contract terminated", "Blacklisted / debarred", "Show-cause notice", "Investigation" (police FIR, EOW, ACB, CBI, ED, SIT, Lokayukta, vigilance inquiry opened), "Chargesheet filed", "Court finding" (a court ruled against them), "Conviction", "Allegation" (raised publicly by politicians/activists/media but not formally actioned), "Cleared" (acquitted, case quashed, blacklisting lifted, inquiry closed with no finding).
- State the current status of each case if known (pending / quashed / settled / unknown). If a later source shows it was cleared, include that too.
- Name individuals ONLY if they were formally charged, arrested, convicted, suspended or named in an official order, and say exactly which. Otherwise refer to roles ("BMC engineers", "company officials").
- Never infer wrongdoing from delays alone. Delays go in the track record, not in "events".
- Prefer Mumbai/Maharashtra matters; include major national matters for the same company (e.g. a debarment by a central ministry) and mark scope.
- Use null where unknown. Do not guess amounts or dates.

Output: write a JavaScript array literal to the path given in your task, then reply with a short summary (count, what's uncertain).
