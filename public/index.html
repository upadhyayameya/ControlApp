Monarch Live Dashboard

Connect your Monarch account. Everything stays on this machine.

If Monarch shows a CAPTCHA on programmatic sign-in, use this instead. Sign in at app.monarch.com, open DevTools → Network → any request → copy the whole Cookie request header (it must contain session_id and csrftoken) and paste it here.

Monarch has no public API, so this uses the same private endpoints its web app does. Your credentials are sent only to Monarch; the session token is stored locally in .monarch/session.json.
